# Автомобиль для анимации

`car-shell.webp` — сгенерированное изображение автомобиля на прозрачном фоне. SVG-панели стёкол подогнаны к оконным проёмам. Все позиции сцены вычисляются по прокрутке, обратная прокрутка обращает движение.

Сцена использует локальное изображение и SVG; внешних библиотек и запросов нет.
