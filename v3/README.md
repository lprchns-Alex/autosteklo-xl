# Автостекло РФ — вариант 3

Отдельная версия сайта с тёмным оформлением и анимацией. Первые две версии остаются в корне репозитория и в `/v2/`.

- `index.html` — содержание и SVG-графика.
- `base.css` — базовые компоненты, сохранённые из предыдущей версии.
- `styles.css` — композиция и адаптивные стили третьего варианта.
- `app.js` — услуги, центры, меню и подготовка заявки.
- `motion.js`, `motion.css` — появление текста и блоков, параллакс, орбиты, карточки при прокрутке и состояния кнопок.
- `assets/brand-logo.svg` — логотип; фотографии используются из общих `../assets/`.

Для просмотра запустите сервер из корня репозитория и откройте `/v3/`. Сборка не требуется.

Анимацию можно приостановить кнопкой на первом экране. Настройка устройства `prefers-reduced-motion` отключает движение. На телефоне большие карточки располагаются последовательно. При недоступности JavaScript основные тексты остаются видимыми.

Форма подготавливает письмо или текст для копирования; автоматическая отправка не подключена.
