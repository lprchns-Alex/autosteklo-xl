# Автостекло РФ — вариант 3

Отдельная версия сайта с дневной и ночной темами и анимацией. Первые две версии остаются в корне репозитория и в `/v2/`.

- `index.html` — содержание и SVG-графика.
- `base.css` — базовые компоненты, сохранённые из предыдущей версии.
- `styles.css` — композиция и адаптивные стили третьего варианта.
- `app.js` — услуги, центры, меню и подготовка заявки.
- `motion.js`, `motion.css` — появление текста и блоков, параллакс, карточки при прокрутке и состояния кнопок.
- `hero-layout.css`, `brands.css`, `bitstop.css` — контакты на первом экране, оригинальные логотипы и партнёрский баннер.
- `theme.js` — переключение темы и сохранение выбора; загружается до стилей, чтобы избежать вспышки другой темы.
- `theme-light.css`, `theme-controls.css` — светлая палитра и кнопка переключения в хедере.
- `assets/` — логотипы, новая фотография hero и баннер Bitstop; остальные фотографии используются из общих `../assets/`.

Для просмотра запустите сервер из корня репозитория и откройте `/v3/`. Сборка не требуется.

По умолчанию открывается одобренная тёмная тема. Кнопка с солнцем или луной в хедере переключает оформление. Выбор сохраняется в `localStorage` под ключом `avtosteklo-v3-theme` и синхронизируется между вкладками. При недоступности хранилища переключатель работает в текущей странице. Без JavaScript отображается тёмная версия, кнопка скрыта.

Настройка устройства `prefers-reduced-motion` отключает движение. На телефоне большие карточки располагаются последовательно. При недоступности JavaScript основные тексты остаются видимыми.

Одобренная версия до добавления переключателя сохранена тегом `v3-approved-2026-11-07` (коммит `be7b749`).

Форма подготавливает письмо или текст для копирования; автоматическая отправка не подключена.
