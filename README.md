# Автостекло.рф — XL GROUPP

Адаптивный сайт услуг по замене и ремонту автомобильных стёкол. HTML, CSS и JavaScript без сборки и серверных зависимостей.

## Локальный запуск

```sh
python3 -m http.server 8765
```

Откройте `http://localhost:8765`.

## Структура

- `index.html` — содержимое страницы и SVG-иконки.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — меню, окна услуг и контактов, выбор чатов MAX, подготовка заявки.
- `assets/` — логотип и изображения.

Шрифт Inter загружается через Google Fonts.

## Заявки и контакты

Форма подготавливает текст заявки и позволяет открыть почтовый клиент или скопировать текст. Автоматическая отправка и CRM не подключены. Контакты и ссылки мессенджеров взяты с действующего сайта автостекло.рф.

## Публикация

Сайт размещается на GitHub Pages из корня ветки `main`. Сборка не требуется.
