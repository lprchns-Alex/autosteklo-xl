# Автостекло РФ — UI kit V3.1

Отдельная страница: https://lprchns-alex.github.io/autosteklo-xl/v3.1/ui-kit/

12 разделов: логотипы, цвета, типографика, сетка и размеры, кнопки, формы, иконки, карточки, навигация, составные блоки, обратная связь и анимация.

## Устройство

- `index.html` — доступные для просмотра и взаимодействия образцы компонентов.
- `ui-kit.css` — оболочка документации и локальная компоновка образцов.
- `ui-kit.js` — демо-диалоги, форма без отправки данных, копирование, навигация и анимация.
- `tokens.json` — выгружаемые значения палитр, типографики, геометрии и движения.
- `icons.svg` — SVG-спрайт иконок сайта. По нажатию на иконку копируется самостоятельный SVG.

Страница подключает CSS и изображения V3.1 по относительным путям. Использует существующий `theme.js`, сохраняющий выбор темы. `app.js` главной страницы не подключён: примеры не отправляют заявки. Disabled, loading, pressed и валидация полей дополнены для библиотеки и не меняют главную страницу.

Изменения оболочки изолированы классом `.kit-page`. HTML-образцы и экспортированные токены нужно синхронизировать при изменении исходных компонентов. Старые версии сайта не затронуты.

## Проверка

Открыть `/v3.1/ui-kit/` на локальном HTTP-сервере. Проверить обе темы, ширины 320/390/1280 px, форму с ошибками и успешным заполнением, открытие и Escape в диалоге, копирование SVG/HEX, меню и повтор анимации. Для анимации учитывается `prefers-reduced-motion`.
